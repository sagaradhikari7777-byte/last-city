# LAST CITY

A mobile-first roguelite survival/city-defense PWA designed for iPhone browsers and Vercel static hosting.

## Playable build features
- Day/night survival loop
- 8 buildable structures plus the City Core
- Food, power, scrap, population/crew and morale economy
- Structure placement, inspection, upgrades and demolition/refunds
- Automatic defenses and projectile combat
- 5 enemy classes including a Titan boss every fifth night
- Random decision events with consequences
- Starvation and morale pressure
- Local autosave / resume
- Offline service worker cache
- Portrait PWA / Add to Home Screen support
- Pause and 2x simulation speed

## Run locally
Serve this folder with any static web server, for example:

    python3 -m http.server 3000

Then open http://localhost:3000.

## Deploy
The folder is ready for a zero-build Vercel static deployment. `vercel.json` is included.
